# 🤖 AI调试器使用指南

## 📖 功能介绍

AI调试器是一个通用的AI对话测试工具，可以帮助你：
- 🎯 测试不同的AI提示词效果
- ⚙️ 调整AI参数（温度、token数等）
- 📋 使用预设模板快速测试
- 💬 查看完整的对话历史
- 📊 监控Token使用情况

## 🚀 快速开始

### 1. 启动服务

确保后端服务已启动：

```bash
cd backend
python api_server.py
```

### 2. 访问调试器

打开前端应用，点击顶部的 **🔧 AI调试器** 标签页。

## 🔧 使用步骤

### 方式1：使用预设模板（推荐新手）

1. **选择预设**: 在左侧下拉框选择一个预设模板（如"标题清洗专家"）
2. **查看配置**: 系统会自动填充系统提示词和参数
3. **输入消息**: 在底部输入框输入你的测试内容
4. **发送**: 点击 📤 发送 或按 `Ctrl/Cmd + Enter`
5. **查看结果**: AI响应会显示在对话区域

### 方式2：自定义配置（高级用户）

1. **设置系统提示词**: 在左侧 "💬 系统提示词" 区域定义AI的角色和行为
2. **调整参数**:
   - **模型**: 选择使用的AI模型（如 `gpt-4o-mini`）
   - **温度**: 0-2之间，越高越随机，越低越确定
   - **最大Tokens**: 控制响应长度
3. **输入消息**: 输入你的问题或内容
4. **发送测试**: 发送并查看效果
5. **迭代优化**: 根据结果调整提示词和参数

## 📊 参数说明

### Temperature（温度）

控制AI响应的随机性和创造性：

| 温度值 | 效果 | 适用场景 |
|--------|------|----------|
| 0.0-0.3 | 🎯 **确定性强** | 数据提取、分类、翻译 |
| 0.4-0.7 | ⚖️ **平衡** | 问答、对话、一般任务 |
| 0.8-1.2 | 🎨 **创意性高** | 文案创作、故事生成 |
| 1.3-2.0 | 🌈 **非常随机** | 头脑风暴、实验性创作 |

**示例对比**：

```
输入: 描述一只猫

Temperature = 0.3:
"猫是一种小型哺乳动物，通常作为宠物饲养。"

Temperature = 1.5:
"在月光下，一只神秘的虎斑猫优雅地踱步，它翡翠般的眼睛闪烁着古老的智慧..."
```

### Max Tokens（最大Token数）

控制AI响应的长度：

- **50-100**: 简短回答（关键词、标签）
- **200-500**: 中等长度（段落、解释）
- **500-1000**: 较长内容（详细说明、代码）
- **1000+**: 长文本（文章、完整代码）

**注意**: 1 token ≈ 0.75 个英文单词 ≈ 1-2 个中文字符

## 🎯 最佳实践

### 1. 提示词编写技巧

**✅ 好的提示词**：
```
你是一个商品标题清洗专家。任务：
1. 提取核心关键词
2. 去除营销词（hot, best, new等）
3. 去除数量词（1pc, 2pcs等）
4. 只返回关键词，用空格分隔

示例：
输入：1pc Hot New Design Cap
输出：design cap
```

**❌ 差的提示词**：
```
帮我清洗标题
```

**为什么差？** 
- 太模糊，没有明确规则
- 没有示例
- 没有输出格式要求

### 2. 迭代测试流程

```
1. 写初始提示词
   ↓
2. 测试几个案例
   ↓
3. 发现问题（如：保留了不该保留的词）
   ↓
4. 修改提示词（添加规则：去除XX词）
   ↓
5. 重新测试
   ↓
6. 重复步骤3-5，直到满意
```

| 问答 | 0.5-0.7 | 200-500 |

## ⚠️ 常见问题

### Q1: 为什么AI响应很慢？

**可能原因**：
- 网络问题（需要代理访问OpenAI）
- Max Tokens设置过大
- 系统提示词太长

**解决方法**：
- 检查代理配置（.env中的HTTP_PROXY）
- 减少Max Tokens
- 精简系统提示词

### Q2: 为什么结果不稳定？

**原因**: Temperature设置过高

**解决**: 降低Temperature到0.1-0.3

### Q3: 为什么响应被截断？

**原因**: Max Tokens设置过小

**解决**: 增加Max Tokens

### Q4: 如何让AI更准确？

1. ✅ 使用低Temperature（0.1-0.3）
2. ✅ 提供明确的规则和示例
3. ✅ 在提示词中强调"必须"、"只返回"等
4. ✅ 使用结构化的输出格式

## 🎓 进阶技巧

### 1. Few-Shot Learning（少样本学习）

在系统提示词中提供多个示例：

```
示例1:
输入: 1pc Vintage Hat
输出: vintage hat

示例2:
输入: 2pcs Modern Design Socks
输出: modern design socks

示例3:
输入: Premium Quality Winter Scarf
输出: winter scarf
```

越多示例 → AI理解越准确

### 2. Chain of Thought（思维链）

让AI展示思考过程：

```
任务：清洗标题
步骤：
1. 识别原标题
2. 列出要去除的词
3. 保留核心词
4. 返回结果

请按此步骤处理：XXX
```

### 3. 使用约束条件

```
约束：
- 必须返回3-5个关键词
- 不能包含任何数字
- 必须全部小写
- 用空格分隔，不用逗号
```
