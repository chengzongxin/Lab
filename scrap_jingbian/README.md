# 百度健康爬虫程序

## 功能介绍

这是一个专门用于爬取百度健康信息的Python爬虫程序，主要功能包括：

1. **读取Excel文件**：自动读取Excel文件第二列的文章标题
2. **百度搜索**：对每个标题进行百度搜索
3. **智能识别**：自动识别带有"百度健康"标志的搜索结果
4. **信息提取**：爬取详情页的标题、医生、医生职位、科室等信息
5. **结果保存**：自动保存到当日新建的Excel文件中

## 安装依赖

在运行程序之前，请先安装所需的Python包：

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 准备Excel文件

确保你的Excel文件包含以下列：
- 第一列：文章部门
- 第二列：文章标题（程序会读取这一列）
- 第三列：爬虫ID

### 2. 运行程序

```bash
python baidu_health_scraper.py
```

### 3. 选择文件

程序会自动检测当前目录下的Excel文件，你可以选择要处理的文件。

### 4. 等待完成

程序会自动：
- 逐个处理每个标题
- 搜索百度健康相关内容
- 提取医生信息
- 保存结果到Excel

## 输出结果

程序会生成一个Excel文件，文件名格式为：`百度健康爬取结果_YYYYMMDD.xlsx`

包含以下列：
- `search_title`：搜索的原始标题
- `title`：百度健康页面的标题
- `doctor`：医生姓名
- `position`：医生职位
- `department`：科室信息

## 注意事项

1. **网络要求**：需要稳定的网络连接
2. **浏览器要求**：程序会自动下载Chrome驱动
3. **反爬虫**：程序包含延迟机制，避免被反爬
4. **日志记录**：所有操作都会记录到`scraper.log`文件中

## 故障排除

### 常见问题

1. **Chrome驱动问题**
   - 确保已安装Chrome浏览器
   - 程序会自动下载匹配的驱动

2. **网络超时**
   - 检查网络连接
   - 适当增加延迟时间

3. **Excel读取失败**
   - 确保Excel文件格式正确
   - 检查文件是否被其他程序占用

### 查看日志

如果遇到问题，请查看`scraper.log`文件，其中包含详细的运行信息。
