# 批量Excel商品名称处理工具使用说明

## 🚀 功能概述

这个工具可以一次性处理多个品类的商品名称，将所有匹配的商品合并到一个输出文件中。

## 📁 文件说明

- `batch_processor.py` - 批量处理脚本（推荐使用）
- `excel_processor.py` - 单品类处理脚本
- `商品基础信息.xlsx` - 你的原始数据文件

## 🎯 支持的品类

当前配置的品类：
- **Sock** → Lite Trend Sock
- **Drawstring** → Lite Trend Drawstring  
- **Tote** → Lite Trend Tote
- **Sports** → Lite Trend Sports
- **Scarf** → Lite Trend Scarf
- **Apron** → Lite Trend Apron
- **Unisex** → Lite Trend Unisex
- **Cooling** → Lite Trend Cooling

## 🔧 使用方法

### 方法1：处理你的实际文件
```bash
python batch_processor.py "商品基础信息.xlsx"
```

### 方法2：使用示例文件测试
```bash
python batch_processor.py
```

## 📋 输出文件

- **文件名格式**：`processed_all_categories_YYYYMMDD_HHMMSS.xlsx`
- **包含内容**：
  - 所有匹配的商品（已重命名）
  - 原始数据的所有列
  - 新增"处理品类"列，标识每个商品属于哪个品类

## ⚙️ 自定义配置

要修改品类配置，编辑 `batch_processor.py` 文件顶部的配置区域：

```python
# 要处理的所有品类配置
CATEGORY_CONFIGS = {
    "Sock": "Lite Trend Sock",
    "Drawstring": "Lite Trend Drawstring", 
    "Tote": "Lite Trend Tote",
    "Sports": "Lite Trend Sports",
    "Scarf": "Lite Trend Scarf",
    "Apron": "Lite Trend Apron",
    "Unisex": "Lite Trend Unisex",
    "Cooling": "Lite Trend Cooling"
}
```

## 🔍 匹配规则

- 匹配模式：`数字 + 空格 + 品类关键词`
- 不区分大小写
- 例如：`Fishes 3 Sports Bags` → `Fishes 3th Lite Trend Sports Bags`

## 💡 优势

1. **一次性处理**：无需逐个品类处理
2. **统一输出**：所有结果合并到一个文件
3. **品类标识**：清楚标识每个商品的品类
4. **详细统计**：显示各品类的处理数量
5. **灵活配置**：轻松添加或修改品类
