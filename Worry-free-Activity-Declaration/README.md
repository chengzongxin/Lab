# 活动申报助手 Chrome 插件

一个基于 React+TypeScript 的 Chrome 插件，用于自动申报活动商品。支持活动申报页面和官方大促页面。

## 功能特性

### 🎯 核心功能
- **自动勾选商品**：根据配置的品类关键词和最低价格自动勾选符合条件的商品
- **多页面支持**：支持活动申报页面和官方大促页面
- **智能滚动**：自动滚动加载更多商品
- **实时状态**：显示勾选进度和状态
- **配置管理**：支持多个品类配置，自动保存

### 📊 页面支持
1. **活动申报页面**
   - 商品名称选择器：`.goods-info_title__yHBeG`
   - 价格选择器：`td:nth-child(5)`
   - 页面特征：包含活动申报相关元素

2. **官方大促页面**
   - 商品名称选择器：`.beast-core-ellipsis-1`
   - 价格选择器：`td:nth-child(5)`
   - 页面特征：包含官方大促相关元素

## 安装和使用

### 1. 安装插件
1. 下载插件文件到本地
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择插件文件夹

### 2. 配置品类
1. 点击浏览器工具栏中的插件图标
2. 在弹出窗口中添加品类配置：
   - **品类关键词**：商品名称中包含的关键词（支持多个关键词，用逗号分隔）
   - **最低价格**：商品价格必须大于等于此价格才会被勾选
3. 点击"保存"按钮

### 3. 开始自动勾选
1. 打开活动申报页面或官方大促页面
2. 点击插件图标
3. 点击"开始自动勾选"按钮
4. 插件会自动检测页面类型并开始工作

### 4. 监控进度
- 插件会显示当前勾选进度
- 达到最大勾选数量（200个）时会自动停止
- 可以随时点击"停止"按钮中断操作

## 技术实现

### 核心算法
1. **页面检测**：自动识别页面类型（活动申报/官方大促）
2. **元素定位**：使用多种选择器确保元素定位的准确性
3. **文本提取**：智能提取商品名称，排除CSS样式代码
4. **价格解析**：正则表达式提取价格数字
5. **关键词匹配**：支持多关键词匹配，不区分大小写
6. **勾选操作**：模拟真实的checkbox点击和状态更新

### 性能优化
- **节流处理**：避免频繁的DOM操作和事件触发
- **批量处理**：一次性处理多个商品
- **内存管理**：及时清理定时器和事件监听器
- **错误处理**：完善的异常捕获和错误提示

### 用户体验
- **实时反馈**：显示操作状态和进度
- **智能停止**：达到限制或出错时自动停止
- **配置持久化**：自动保存用户配置
- **多语言支持**：中文界面和提示

## 常见问题

### Q: 插件无法启动？
A: 请确保在正确的页面上使用，并刷新页面后重试。

### Q: 商品没有被勾选？
A: 请检查：
1. 关键词是否与商品名称匹配
2. 价格是否满足最低要求
3. 使用调试工具检查页面元素

### Q: 滚动功能不工作？
A: 请使用 `debugTools.checkScrollContainers()` 检查滚动容器。

### Q: 如何添加新的品类？
A: 在插件弹出窗口中点击"添加品类"按钮，输入关键词和最低价格。
