## 功能简介

这是一个Chrome浏览器插件，用于自动申报活动商品。插件会根据配置的品类关键词和最低价格，自动勾选符合条件的商品，提高申报效率。

## 主要功能

- ✅ **自动勾选**：根据品类关键词和最低价格自动勾选商品
- 📊 **实时进度**：显示勾选进度和数量统计
- 🛑 **智能停止**：达到200个商品限制时自动停止
- ⚡ **性能优化**：减少页面卡顿，优化检查频率
- 🔧 **调试工具**：提供丰富的调试命令

## 安装方法

1. 下载插件文件到本地目录
2. 打开Chrome浏览器，进入 `chrome://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择插件目录，完成安装

## 使用方法

### 1. 配置品类
- 点击插件图标打开配置界面
- 添加品类关键词（如：袜子、围裙）
- 设置最低申报价格
- 支持多个关键词（用逗号分隔）

### 2. 开始自动勾选
- 进入活动申报页面
- 点击"开始自动勾选"
- 插件会自动扫描页面并勾选符合条件的商品

### 3. 监控进度
- 查看实时勾选进度
- 达到200个商品限制时自动停止
- 可随时手动停止
