# 🎯 活动申报助手 Chrome 插件

一个智能的Chrome浏览器插件，帮助用户自动根据配置的品类和最低价格勾选符合条件的商品进行活动申报。

## ✨ 主要功能

- **智能品类匹配**: 根据商品名称中的关键词自动匹配品类
- **价格阈值判断**: 自动判断申报价格是否达到最低要求
- **实时监控**: 监听页面变化，自动处理新加载的商品
- **可视化反馈**: 提供清晰的操作状态和结果反馈
- **配置管理**: 支持添加、编辑、删除品类配置

## 🚀 安装方法

### 方法一：开发者模式安装（推荐）

1. 下载或克隆此项目到本地
2. 打开Chrome浏览器，进入扩展程序页面：
   - 在地址栏输入：`chrome://extensions/`
   - 或者点击菜单 → 更多工具 → 扩展程序
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目文件夹
6. 插件安装完成！

### 方法二：打包安装

1. 在扩展程序页面点击"打包扩展程序"
2. 选择项目根目录
3. 生成.crx文件后拖拽到扩展程序页面安装

## 📖 使用说明

### 1. 配置品类

1. 点击浏览器工具栏中的插件图标
2. 在弹出窗口中配置品类信息：
   - **品类关键词**: 输入商品名称中包含的关键词（如：袜子、围裙）
   - **最低价格**: 设置该品类的最低申报价格
3. 点击"➕ 添加品类配置"可以添加更多品类
4. 配置会自动保存

### 2. 开始自动勾选

1. 打开活动申报页面
2. 点击插件图标，然后点击"🚀 开始自动勾选"
3. 插件会自动扫描页面上的商品：
   - 检查商品名称是否匹配配置的品类
   - 判断申报价格是否达到最低要求
   - 自动勾选符合条件的商品
4. 当页面滚动加载新商品时，插件会自动处理

### 3. 停止自动勾选

- 点击"⏹️ 停止自动勾选"可以随时停止自动处理

## 🔧 技术特性

- **实时监听**: 使用MutationObserver监听DOM变化
- **智能匹配**: 支持多关键词匹配（用逗号分隔）
- **性能优化**: 避免重复处理已检查的行
- **错误处理**: 完善的错误处理和用户反馈
- **数据持久化**: 配置数据自动保存到浏览器存储

## 🎨 界面说明

### 弹出窗口功能

- **品类配置区域**: 显示所有配置的品类和最低价格
- **添加按钮**: 新增品类配置
- **开始按钮**: 启动自动勾选功能
- **停止按钮**: 停止自动勾选功能
- **状态显示**: 显示当前操作状态和结果

### 页面反馈

- **通知提示**: 右上角显示操作状态通知
- **视觉反馈**: 被勾选的行会短暂高亮显示
- **控制台日志**: 详细的操作日志（按F12查看）

## ⚙️ 配置说明

### 品类配置格式

```javascript
{
  keyword: "袜子, 短袜",  // 支持多个关键词，用逗号分隔
  minPrice: 10.5         // 最低价格，支持小数
}
```

### 支持的页面元素

插件会自动识别以下页面元素：
- 商品名称: `.goods-info_title__yHBeG`
- 申报价格: 第5列的价格信息
- 复选框: `input[type="checkbox"]`

## 🐛 故障排除

### 常见问题

1. **插件无法启动**
   - 检查是否在正确的页面上使用
   - 确认页面已完全加载
   - 查看浏览器控制台是否有错误信息

2. **无法识别商品**
   - 检查品类关键词是否正确
   - 确认商品名称元素存在
   - 查看页面结构是否发生变化

3. **价格识别错误**
   - 检查价格元素的位置
   - 确认价格格式是否正确
   - 查看控制台日志了解详情

### 调试方法

1. 打开浏览器开发者工具（F12）
2. 在控制台中输入 `window.autoCheckManager` 查看插件状态
3. 使用 `window.autoCheckManager.getPageStats()` 获取页面统计信息
