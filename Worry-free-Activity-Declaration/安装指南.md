# 🚀 快速安装指南

## 第一步：准备文件

确保你有以下文件：
- `manifest.json`
- `popup.html`
- `popup.js`
- `content.js`
- `background.js`
- `icons/` 文件夹（包含图标文件）

## 第二步：安装插件

1. **打开Chrome浏览器**
2. **进入扩展程序页面**：
   - 在地址栏输入：`chrome://extensions/`
   - 或者点击右上角菜单 → 更多工具 → 扩展程序

3. **开启开发者模式**：
   - 点击右上角的"开发者模式"开关

4. **加载插件**：
   - 点击"加载已解压的扩展程序"
   - 选择包含所有文件的文件夹
   - 点击"选择文件夹"

5. **确认安装**：
   - 插件应该出现在扩展程序列表中
   - 浏览器工具栏会显示插件图标

## 第三步：使用插件

1. **打开活动申报页面**
2. **点击插件图标**打开配置窗口
3. **配置品类**：
   - 输入品类关键词（如：袜子、围裙）
   - 设置最低价格
   - 可以添加多个品类配置

4. **开始自动勾选**：
   - 点击"🚀 开始自动勾选"
   - 插件会自动扫描并勾选符合条件的商品

5. **监控结果**：
   - 查看页面右上角的通知
   - 被勾选的行会短暂高亮显示
   - 按F12查看详细日志

## 注意事项

⚠️ **重要提醒**：
- 请确保在正确的活动申报页面上使用
- 插件会自动保存你的配置
- 可以随时停止自动勾选功能
- 建议先在小范围测试后再大规模使用

## 故障排除

如果遇到问题：
1. 检查浏览器控制台（F12）是否有错误信息
2. 确认页面已完全加载
3. 重新加载插件或刷新页面
4. 检查品类配置是否正确

## 图标文件说明

当前使用的是占位符文件，你需要：
1. 准备16x16、48x48、128x128像素的PNG图标
2. 替换 `icons/` 文件夹中的文件
3. 或者暂时删除manifest.json中的icons配置
